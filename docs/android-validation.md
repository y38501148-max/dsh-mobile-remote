真机和跨网项目仍以本文末尾的未实测边界为准。[参考项目与实现范围](reference-and-mobile-ui.md) 说明本次手机界面及直连诊断的具体变化。

# Android 0.2.0-preview.1 验证记录

日期：2026-09-09。软件为预览版；外部网络与真机项目单独列出。

## 已执行

- 电脑插件 34 项单元测试、9 项 Host/原生协议/网关/中继/安装集成测试、1 项现有插件兼容集成测试通过，共 44 项。
- 安卓 Debug 和签名 Release 构建通过；两种构建的 6 项网络身份测试通过，Android lint 无错误。
- 信任测试覆盖：错误公钥、过期证书、主机名不匹配、续期保留公钥、跨 origin 拒绝、IPv6 二维码与过期；固定覆盖公钥包含 `+` 的编码情况。
- Android 16 / API 36、ARM64 Google APIs 模拟器，真实隔离 Harness rc.6 Host、合成会话与本地模拟模型：配对/电脑批准、Cookie 不进入页面 JavaScript、会话列表/创建/发送、WebSocket 流式结束事件、历史读取通过。
- 同一场景验证 264,000 字节文本的分块上传/读取及 SHA-256；安卓系统文件选择器真实选择 UTF-8 文本；系统“另存为”保存 512 KiB 二进制文件，拉回逐字节一致。
- 可选前台提醒服务建立真实事件连接，任务完成产生不含正文的系统通知；停止服务、Activity 重建并恢复加密授权通过。
- 签名发行包通过正常原生“粘贴配对链接”界面连接真实 Host；确认忽略 debug-only Intent、同签名覆盖安装、强制结束后重新启动均恢复原授权，没有重复配对。
- 发行 APK 使用独立 RSA 4096 发布密钥，APK v2 签名验证通过；非 debug 包，最低 SDK 29、目标 SDK 36。
- 本机真实桌面 profile 已安装插件 0.2.0，IPv6 入口开启，带 IP SAN 的 TLS 校验及 `/remote/info` 协议/Host 身份检查通过；未改变系统 CA 信任。

签名证书 SHA-256：`3fcf712365943162dab9e7f777afbd704a11fc798d1cf8b08eeeef26ba0d4b56`。APK 文件摘要与两个源码提交由每次 Release 的 `release-manifest.json` 记录，避免把不同构建的摘要混为一谈。

自动化复现入口：安卓仓库 `scripts/run-emulator-test.py`，签名包使用 `scripts/run-signed-smoke.py`；插件仓库 `scripts/android-fixture.mjs` 创建隔离 Host。生产配对仍由电脑用户确认，自动批准逻辑只存在测试 helper。

## 尚未实测的边界

- iQOO 15 真机安装、相机扫码、权限拒绝后恢复、锁屏与厂商后台管理。
- 手机关闭 Wi-Fi 后的蜂窝 IPv6 入站、另一外部网络，以及实际 Wi-Fi/蜂窝切换。
- 长时间后台、电量影响、Android 前台服务时长限制、超过服务时长后的重新开启。
- 电脑校园网前缀实际改变及跨网恢复。地址选择、稳定判定和证书重签已自动测试，不能代替真实网络迁移。

模拟器没有真实运营商网络；本机访问自己的 IPv6 不能证明校园网允许外部入站。预览版不承诺关闭/强制停止 App 后即时通知，也不自动部署域名或中继。以上未实测项不标记为通过。
