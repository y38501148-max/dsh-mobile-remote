## 浏览器验收

使用 ego lite 独立任务空间，以 1440px 桌面视口和 390×844 手机视口连接同一个测试 Host：

- 手机编辑文字，电脑续接发送；手机再次发送。发送被原生模型拒绝时保留草稿。
- 图片与文本文件从手机恢复到电脑；页面刷新保留图片；仅支持文本的模型拒绝图片后仍可恢复输入。
- 会话、对话/轨迹/详情面板、阅读位置及展开状态共享；退出跟随和接管有独立入口。
- 问题、审批、可见 reasoning、轨迹和插件设置页面可呈现；只读设备不能修改业务状态。
- 修复手机标题、输入工具条与设置布局；390px 页面无横向溢出，设置导航改为横向滚动，弹窗打开时隐藏插件悬浮条。
- 长断线期间生成 35 个模拟回合，恢复后补读历史：1591 条事件，序号 0–1590 无缺口；桌面与手机完整原始事件 JSON 的 SHA-256 相同。测试证书采用浏览器调试会话临时忽略证书错误，未修改系统信任；不将该测试的恢复耗时作为生产性能指标。

## 实现边界

手机复用同一 Host 的原生客户端和事件协议；独立网关只处理认证、授权、传输与共享辅助状态。首次安装关闭；显式开启后的配置可重启恢复。设备授权、草稿和回执持久保存，状态目录加独占锁。手机断线不取消 Host 工作。

原生 prompt 接收加入持久证据对账；回执只证明接收，不证明任务完成。若崩溃前没有持久证据，保留“结果待确认”，不自动重发。不宣称所有任意副作用都有跨进程 exactly-once 保证。

文件按设备与会话授权；普通角色限制工作区，完整控制可读工作区外。图片/文本草稿有大小、总量、哈希、归属和清理限制；产物流式读取支持媒体 Range。推送只发通用提醒。防休眠针对 macOS 空闲休眠，不能绕过关机、主动休眠或合盖限制。

## 进入真机实验

代码、打包和本机集成已具备实验条件。接下来需要实际设备及网络验证：

1. 安卓使用已安装的 0.2.0 插件，选择 IPv6 地址并扫码固定电脑公钥；浏览器/PWA 仍需要受浏览器信任的 HTTPS 证书。
2. 两端交替输入、附件发送、审批、排队/停止和断网恢复，确认真实供应商行为。
3. 手机锁屏、后台、Wi-Fi/蜂窝切换、PWA 与系统 Web Push。
4. 桌面窗口隐藏、Host 持续运行、防空闲休眠及长时间资源占用。
5. 选定公网中继域名与机器后部署，测试跨网稳定性；本轮没有创建付费资源或部署公网服务。

实验发现的缺陷继续修复；以上待验收项不标记为已经通过。
